# The 76 Wisdoms of Success — Flagship Edition

This folder contains the flagship editorial edition of Ahmad Sulaimiy's manuscript, transformed from the original working draft (`70_wisdoms_AutoRecovered.docx`) into a restructured, professionally typeset book.

## What's in the file

`The-76-Wisdoms-of-Success-Flagship-Edition.docx` (editable manuscript) and `.pdf` (print-ready, identical layout) are a complete book, 6"×9" trim, including:

- Full front matter: half title, title page, copyright page, dedication, foreword, author's preface, "How to Use This Book," and an original introduction essay ("The Islamic Philosophy of Success")
- Six thematic parts (Foundations, Wealth & Financial Intelligence, Leadership & Influence, Character & Excellence, Relationships & Social Impact, Faith/Barakah/Legacy), each with its own divider page
- All 76 wisdoms, each restructured into: Arabic proverb, English translation, Core Reflection, Qur'anic Foundation, Prophetic Guidance, Scholarly Insight (where present in the source), Contemporary Application, three Action Points, a Reflection Question, and a Legacy Principle
- End matter: Final Reflection, Author's Closing Message, Recommended Reading, Glossary, Qur'an Index, Hadith Index, Scholar Index, Subject Index, About the Author, About Future Publications
- A designed front and back cover page (Deep Royal Navy / Imperial Gold / Warm Ivory palette)

## Editorial notes

- **Wisdom count:** The source manuscript contains 76 distinct wisdom entries, not 70. Per an explicit decision made with the requester, the edition keeps all 76 and retitles the book accordingly ("The 76 Wisdoms of Success") rather than cutting six entries to force-fit the original working title.
- **Translations:** 8 of the 76 English wisdom-lines were present verbatim in the source manuscript; 53 more were recovered from the author's own "next wisdom" preview lines embedded at the end of adjacent commentaries; the remaining 15 were translated directly from the Arabic for this edition.
- **Citations:** Every Qur'an verse, hadith, and scholar quotation shown in the book was extracted from the author's original commentary — nothing was invented. Where the source commentary did not include one of these three source types for a given wisdom, that box is simply omitted rather than filled with a fabricated citation.
- **New editorial content:** Core Reflection, Contemporary Application (condensed/polished), Action Points, Reflection Questions, and Legacy Principles were drafted for each wisdom, grounded strictly in that wisdom's own source commentary.

## Formatting note

The document is 178 pages. It has been validated against the DOCX schema (passed) and visually proofed page-by-page as a rendered PDF (cover, front matter, every wisdom template variant, part dividers, indices, and back cover). Typeset in EB Garamond (Latin) and Amiri (Arabic) — both free, widely available fonts — so it renders correctly even on machines without premium commercial fonts installed.
