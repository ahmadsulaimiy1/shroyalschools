# 06 — Copywriting (Verbatim)

All Arabic text is reproduced **exactly as published**, including original punctuation,
diacritics and spelling. English glosses are translations for the rebuild team and are
**not** on the live site unless marked *(live)*.

> ⚠ **Migration rule:** Quranic and religious terminology carries diacritics
> (`مِقْرَأَةُ إِتْقَانَ الِافْتِرَاضِيَّةُ`) that must survive copy-paste, database encoding and
> font rendering. Verify UTF-8 end-to-end and never "normalise" these strings.

## 11. Terms — `شروط القبول والتسجيل`

Consent line:
```
🔘 الضغط على زر (التسجيل الآن) يُعد إقرارًا بالاطلاع والموافقة على جميع شروط القبول والتسجيل.
```

**أولًا: رسالة المقرأة ومنهجها**
```
مقرأة إتقان الافتراضية مختصة بتعليم القرآن الكريم فقط. يقتصر دورها على:
  • تعليم التلاوة الصحيحة
  • إتقان أحكام التجويد
  • الحفظ والمراجعة
  • توفير الدعم بالهدايا والتحفيز للمستفيد ليتعلم وفق بيئة جاذبة مشجعة للإنجاز.
يُمنع الخروج عن هذا الإطار، ويكون ما يتعلّق بـ التدبر أو التفسير بالرجوع إلى المصادر
الموثوقة المعتمدة.
```

**ثانيًا: آلية التسجيل**
```
يتم التسجيل حصريًا عبر رابط المقرأة الرسمي وتعبئة البيانات المطلوبة، ولا يُعتد بأي تسجيل
يتم من خارج المنصة.
```

**ثالثًا: الضوابط العامة**
```
الحلقات مخصصة لتعليم القرآن الكريم فقط.
يُمنع منعًا باتًا:
  • إرسال أي رسائل أو محتوى لا علاقة له بالحلقة.
  • التواصل الخاص بين الأعضاء لغير أغراض التعليم.
```

**رابعًا: الالتزام والمتابعة**
```
  • الالتزام بالإنجاز اليومي قدر المستطاع.
  • رفع تقرير التسميع عبر المنصة بعد الانتهاء.
  • الالتزام بالحضور في الوقت المحدد.
  • إبلاغ المعلم أو إدارة المقرأة عند التغيب بعذر مناسب.
```

**خامسًا: صحة البيانات**
```
  • يشترط تسجيل الاسم ثلاثيًا صحيحًا.
  • إدخال بريد إلكتروني ورقم جوال صحيحين.
  • يتحمل المسجّل كامل المسؤولية عن صحة البيانات المدخلة.
```

**سادسًا: الدعم والرعاية**
```
تتيح المقرأة إمكانية دعمها والمساهمة في استمرارها عبر متجر جمعية مكنون لتحفيظ القرآن الكريم.
```
⚠ Mentions a Maknoon store as the donation route but **provides no link**.

**سابعًا: الملاحظات والمقترحات**
```
يسعد إدارة المقرأة استقبال الملاحظات والاقتراحات والاستفسارات عبر التواصل المباشر مع إدارة
المقرأة نتشرف بخدمتكم.
```
⚠ `يسعد إدارة المقرأة` should be `تسعد` (feminine agreement with `إدارة`).

**Consent controls:** `قرأت الشروط وأوافق عليها بالكامل` → `[ موافق ومتابعة ]`

> **Clause 4 is the most important content on the site for the rebuild:** it reveals that
> students must *"رفع تقرير التسميع عبر المنصة"* — submit a recitation report through the
> platform. This confirms the LMS has an attendance/assessment reporting loop. See `08-lms.md`.
