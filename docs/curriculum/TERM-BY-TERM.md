# الجدول الفصلي · TERM-BY-TERM COURSE LISTS
## What a student actually studies, term by term, in each of the twelve classes

**This is the university shape you described.** A term is a **distinct set of
courses**, not a slice of a year. Some courses run in every term because the
next thing cannot be taught without them. Others appear in **one term only**,
are finished, examined, and do not return until a later class at a higher level.

| | |
|---|---|
| **أساس** | runs in all three terms — a cornerstone. Something later depends on it |
| **فصلي** | a term course — **٢٦ حصة in one term**, finished and examined in that term |
| **مستضاف** | taught inside a named host; no block of its own |
