# كل صف · عدد مواده · صيغة كل مادة · بالتفصيل

## مفتاح الصيغ

| الصيغة | التعريف | له خانة في الجدول؟ | له ورقة؟ |
|---|---|---|---|
| **مستقل** | مادة قائمة بذاتها | **نعم** | نعم |
| **مدمج** | يشترك في خانة شريك مسمّى، وفي ورقته بقسم مسمّى وأرضية ٤٠٪ | يشترك | قسم مسمّى |
| **مضمّن** | يُدرَّس داخل مضيف مسمّى، بلا خانة | لا | داخل المضيف |
| **وحدة** | مقرر محدود مسمّى داخل مضيف، يُمتحن على حدة | لا | تقدير إنجاز (قسم ب) |
| **مسار** | خيط داخل التربية الإسلامية في الابتدائي — درجة واحدة، وصف بلا رقم | لا | ملحق وصفي |

**المدة:** *سنة كاملة* = الفصول الثلاثة · *فصلي* = فصل أو فصلان، يُنهى ويُمتحن فيه
