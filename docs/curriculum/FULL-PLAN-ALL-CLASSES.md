## 2. My judgement on dropping a subject for a term, then returning

**You are right, and it is already how three sciences run.** But it is right for
one class of subject and wrong for another, so the rule has to be stated or it
will be misapplied.

| | Non-contiguous span | Verdict |
|---|---|---|
| **Term courses** | البلاغة: JSS3 ف١ → SS1 ف١ → SS2 ف٣ · مصطلح الحديث: JSS3 ف٣ → SS1 ف٣ → SS2 ف١ · **الفرائض: SS2 ف١+ف٢ → SS3 ف١** | **Right, and adopted.** The gap is not a loss — it is spacing. The science settles, then returns **at a higher level, never as repetition.** |
| **Cornerstones** | your example: الفقه in SS1 ف١+ف٢, dropped ف٣ | **Wrong, and I would advise against it.** الفقه runs a cumulative matn ladder — الأخضرية → الرسالة → القدوري → بداية المجتهد. A term's gap breaks the chain, and SS1 ف٣ is precisely when comparative method is running. The same holds for النحو، العقيدة، الحديث، التفسير، اللغة العربية. |

**The rule:** *a cornerstone never has a gap; a term course may, provided the
return is at a higher level and is written into the scheme before the gap is
approved. A gap with no scheduled return is not a gap — it is a termination,
and must be minuted as one.*

**الفرائض is the exact case you described**, and it is in the plan: **SS 2 first
and second terms** (متن الرحبية, ٥٢ حصة), then absent, then **SS 3 first term**
as الفرائض التطبيقية — the Nigerian courts, the Marriage Act, ìdí-ìgì and
orí-ọjọ́rí. Theory, settle, application.
