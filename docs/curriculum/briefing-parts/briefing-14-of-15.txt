PART 13 - HOW THE LOCK IS ENFORCED MECHANICALLY
================================================================================

A register that only a reader checks is how every previous decision was lost.
So the register is now enforced by a script.

    RUN:  cd docs/curriculum && python3 verify.py

It checks the allocation data against the register and EXITS NON-ZERO if any
locked item is broken. A non-zero exit means the document is not ready and is
not published.
