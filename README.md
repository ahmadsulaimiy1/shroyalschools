# Misbaha — Global Islamic Luxury Tasbeeh Platform

Misbaha is a luxury Islamic Tasbeeh & Dhikr spiritual engagement platform, built Android-first
with a roadmap to iOS, Web, Wear OS/watchOS, TV, and automotive surfaces.

- **[/docs](docs/00-README.md)** — the full product, design, engineering, governance, and
  go-to-market documentation set (PRD, UI/UX design system, brand identity, Android architecture,
  database schema, API docs, admin dashboard, monetisation, security, deployment, five-year
  roadmap, store publishing package).
- **[/android](android)** — a working Android application scaffold (Kotlin, Jetpack Compose,
  Room, Hilt) implementing the core Tasbeeh Counter experience described in the docs.
