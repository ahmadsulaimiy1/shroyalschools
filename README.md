# Sultan Hanafi Royal Schools — ceremony documents

مدارس السلطان حنفي الملكية

Design source for the school's graduation print material. Two A4 documents are
generated from one shared design system, so a change to the palette, the type
scale or the ornament moves both together.

| Document | Source | Output |
|---|---|---|
| Graduation Ceremony Brochure — order of proceedings | `prospectus/graduation-ceremony-brochure.html` | `dist/graduation-ceremony-brochure.pdf` |
| Graduand Yearbook — the class keepsake | `prospectus/graduand-yearbook.html` | `dist/graduand-yearbook.pdf` |

Nine A4 pages each, print-ready at 210 × 297 mm with no margins.

## The content is data, not markup

Nothing that changes year to year lives in the HTML. Edit the JSON, re-run the
build, and both documents update:

| File | Holds |
|---|---|
| `data/school.json` | Name, Arabic name, telephone numbers, website, what the school provides |
| `data/ceremony.json` | Session, date, venue, dignitaries, order of proceedings, awards, the two addresses, acknowledgements |
| `data/graduands.json` | The class roll, the ḥuffāẓ, the prefects |

Every value written in angle brackets — `⟨like this⟩` — is a placeholder still
awaiting confirmation, and it prints in gold with a dotted underline so an
unfinished document can never be mistaken for a finished one.

Only facts visible on the school's own signage are asserted anywhere. Anything
not on the signage is `null` in `data/school.json` and must be supplied.

### The roll carries a draft banner

While `"verified": false` in `data/graduands.json`, both roll pages print a
DRAFT banner. Set it to `true` only once a member of staff has checked every
spelling against the register; the banner then disappears.

`data/NAMES-FROM-PHOTO.md` is a best-effort reading of the handwritten name
cards in `assets/source/graduands-name-cards.jpg`, offered as a prompt for the
registrar. It is not data — several names are ambiguous, and that photograph
appears to show class positions or prefects rather than the graduating set.

## Building

```bash
python3 build/optimize_assets.py          # assets/source -> assets/web
python3 build/build.py                    # data -> prospectus/*.html
python3 build/bundle.py --mode print      # self-contained copies for printing
python3 build/render_pdf.py               # dist/*.pdf
```

`optimize_assets.py` only needs re-running when a source photograph changes.
Day to day, editing the JSON and running `build.py` is enough — open the HTML
in a browser and print to PDF.

Requires Python 3 with Pillow, and Chromium for PDF rendering.

## Design system

**Type.** Adobe Caslon Pro for display and headings, Source Serif 4 for body
copy and the roll, Source Sans 3 for labels and captions, Adobe Arabic for
Arabic. Loaded from an Adobe Fonts kit.

**Colour.** Royal blue `#14305E` with gold `#B98F33` on ivory `#FAF6EC`, drawn
from the school's own crest and graduation stole. Body text stays on
combinations that clear WCAG AA; gold is used for display sizes, rules and
ornament only.

**Ornament.** The eight-point khātam star is drawn as inline SVG from the same
two-overlapping-squares construction as the star on the school badge, and
recurs as the section divider and in the corners of the cover frames.

## Assets

`assets/source/` holds the original photographs and artwork, untouched.
`assets/web/` holds derivatives generated by `optimize_assets.py`: the crest,
award seal and stole cut out of their white studio backgrounds to alpha, plus
downscaled photographs. `assets/web/crest-mark.png` is the crest without its
wordmark, for covers where the school name is already set in type below it.

## Adobe Express

`prospectus/*.html` is authored to import into Adobe Express as an editable
document: one `.page` root per printed page, a declared `hz:slide-selector`,
canvas dimensions on every root, no animation or script, and the Adobe Fonts
link left exactly as the fontkit returned it.

To import, run `python3 build/bundle.py --mode express` and hand the resulting
`dist/*.express.html` to Adobe Express. Those bundles keep the Adobe Fonts link
and inline the images, so they carry everything the importer needs.

### Why the print bundle substitutes fonts

`bundle.py --mode print` swaps the Adobe families for openly-licensed
equivalents and embeds the font files, so a PDF can be rendered anywhere
without reaching Adobe Fonts:

| Adobe Fonts | Print substitute |
|---|---|
| Adobe Caslon Pro | EB Garamond |
| Source Serif 4 | Source Serif 4 (the same typeface) |
| Source Sans 3 | Source Sans 3 (the same typeface) |
| Adobe Arabic | Amiri |

Two of the four are the same typeface either way. Only the Caslon and the
Arabic differ, and only in the PDF — `prospectus/*.html` always keeps the real
Adobe Fonts kit.
